Luma Client Operations Dashboard

A modern and responsive client operations dashboard built with HTML, CSS, and JavaScript.

Features

- 📊 Dashboard overview
- 👥 Client management
- 🧾 Invoice management
- 💰 Expense tracking
- ✅ Task management
- 📈 Revenue and financial reports
- 🔔 Notifications
- 🌙 Dark / Light mode
- 🔎 Search and filtering
- 💾 Local data persistence
- 📱 Responsive design
- ⚡ Quick Add actions

Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Browser LocalStorage

Getting Started

Clone the repository:

git clone YOUR_REPOSITORY_URL

Open the project folder and launch "index.html" in your browser.

No backend or database setup is required for the current version.

Project Structure

Luma-Dashboard/
├── index.html
├── style.css
├── script.js
└── README.md

Data Storage

The current version uses the browser's LocalStorage to save clients, invoices, expenses, tasks, activities, notifications, and theme preferences.
